# Plans de formation — SGEP Fodeba Keita

Durée indicative par session : **2 à 3 heures** + exercices pratiques.

---

## Session 1 — Secrétaire / Scolarité

**Objectifs :** inscriptions, affectations, listes, bulletins administratifs

| Module | Durée | Contenu |
|--------|-------|---------|
| Connexion & navigation | 20 min | Login, sidebar, recherche |
| Inscriptions | 45 min | Nouvel élève, réinscription, transfert |
| Classes | 30 min | Affectation, listes PDF |
| Bulletins admin | 30 min | Génération, impression |
| Q&R | 15 min | |

**Exercice :** inscrire 3 élèves fictifs, les affecter, imprimer la liste de classe.

---

## Session 2 — Économe / Comptable

**Objectifs :** encaissements, impayés, comptabilité, paie

| Module | Durée | Contenu |
|--------|-------|---------|
| Finance | 45 min | Paiement, reçu PDF, situation élève |
| Impayés | 30 min | Liste, relances |
| Comptabilité | 45 min | Dépenses, budget, exports |
| Paie | 30 min | Génération mensuelle |
| Q&R | 15 min | |

**Exercice :** encaisser un paiement, consulter le solde, exporter le journal du mois.

---

## Session 3 — Enseignants

**Objectifs :** notes, présences, mode hors ligne

| Module | Durée | Contenu |
|--------|-------|---------|
| Notes | 45 min | Grille, saisie, absences |
| Présences | 30 min | Appel quotidien |
| Mode offline | 30 min | Coupure réseau, synchronisation |
| EDT | 15 min | Consultation emploi du temps |
| Q&R | 15 min | |

**Exercice :** saisir une évaluation, faire l'appel, simuler une coupure réseau.

---

## Session 4 — Directeur

**Objectifs :** pilotage, rapports, sécurité

| Module | Durée | Contenu |
|--------|-------|---------|
| Dashboard KPI | 30 min | Indicateurs clés |
| Rapports | 45 min | Effectifs, finances, pédagogie |
| Validation bulletins | 30 min | Verrouillage période |
| Sécurité | 30 min | Audit, clôture année, sauvegardes |
| Q&R | 15 min | |

**Exercice :** générer le rapport effectifs T1, consulter le journal d'audit.
